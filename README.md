# Trabajo POO - Sistema de gestion

Requisitos: Java 17 o superior y Apache NetBeans.

Como ejecutarlo:
1. Abrir la carpeta del proyecto con File > Open Project.
2. Ejecutar con F6 (clase principal: trabajo.poo.TrabajoPoo).
3. En la ventana de inicio, pulsar "Registrarse" para crear un usuario
   y luego "Iniciar sesion".

Modulos: Pacientes, Personal medico, Medicamentos, Citas y Usuarios.

Integrantes: Jhoao, Alison, Benjamin, Leonel y Mathias.
